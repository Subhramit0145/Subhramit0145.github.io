# Subhramit Bera — AI Engineer Portfolio

A sleek, responsive, high-performance portfolio website built for showcasing autonomous AI agent architectures, multi-hop RAG systems, and systems-level engineering.

## 🚀 Live Demo
- **URL**: [https://subhramit0145.github.io](https://subhramit0145.github.io)

## 🛠️ Built With
- **Vanilla HTML5, CSS3 & JavaScript** (Zero heavy framework overhead, instant load times)
- **Web Audio API** synthesized reactive audio feedback
- **Command Palette CLI (`Ctrl + K`)** for keyboard-driven navigation
- **Interactive LangGraph Visualizer** & live agent stream simulation
- **Mobile-Responsive & Accessibility Ready**

## 📂 Project Structure
```
├── index.html        # Main semantic markup & metadata
├── style.css         # Custom cyber-editorial design system & animations
├── script.js         # Reactive components, audio synth & command palette
├── assets/           # Profile images and icons
└── README.md         # Documentation
```

## 🌐 Deployment
This portfolio is configured for zero-build static hosting via **GitHub Pages**, **Vercel**, or **Netlify**.
